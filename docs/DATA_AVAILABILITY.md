# Data availability

The clinical dataset used for this project **is not included in this repository and will not be released with it**. This is an ethical and data-governance decision by the project owner, not a claim that de-identification would make redistribution acceptable.

The restricted material includes the source cohort, cleaned/imputed/derived participant-level tables, visit identifiers, outcome and predictor rows, split assignments, out-of-fold predictions, bootstrap resamples, patient-level SHAP values, and fitted model packages. None of these are present in any commit.
